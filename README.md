# MultiMind Windows Portable

Portable WPF-Desktop-App für das vorhandene MultiMind-FastAPI-Backend.

## Automatischer EXE-Build
Repository zu GitHub hochladen, Actions öffnen, `Build Windows Portable EXE` starten und das Artefakt herunterladen.

## Nutzung
1. Backend starten.
2. `MultiMind.exe` öffnen.
3. Backend-Adresse eintragen, standardmäßig `http://localhost:8000/`.
4. Modelle laden und chatten.

Die EXE enthält keine Provider-API-Schlüssel. Diese bleiben im Backend.
